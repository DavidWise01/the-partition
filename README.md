> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **ARTFULLY CRAFTED INTELLIGENCE**.

THE PARTITION — intent↔evidence separation, the ACI CORE property that keeps what a claim ASSERTS apart from what BACKS it. Two ledgers: INTENT rows (free assertions) and EVIDENCE rows (each carrying a recomputable anchor). ⚑ The separation is enforced by TYPE, not by columns: a row backs an intent only if it carries kind:hash + a 64-hex anchor AND sha256(payload)===anchor (the same SHA-256 as [[the-sealing-bench]] / dlw.py). CONTROL ARM: press 'smuggle an intent into evidence' — the assertion lands in the evidence column with no anchor, so it is UNVERIFIABLE, backs nothing, its intent flips UNBACKED, and the verdict drops to INCOMPLETE. Tamper a payload or flip one hex of an anchor → BROKEN → INVALID. Three-state verdict (VALID / INCOMPLETE / INVALID) keeps an unbacked claim distinct from a tampered one. Node-verified 18/18. Two-layer honest: REAL = the type discipline + genuine hash recompute (an assertion has nothing to recompute, so it is structurally rejected); FIGURE = the 'two ledgers', and the sharp caveat that VERIFIED means 'unaltered since sealed', NOT 'true' — a false payload can verify; this checks integrity + presence + non-masquerade, never truth of content. Anchoring is LOCAL, as [[the-anchor]] discloses. periwinkle/sea. David Lee Wise (ROOT0), with AVAN.
